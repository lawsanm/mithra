# Generated item photography

Created with the built-in ImageGen tool for Mithra. These are illustrative photos for seeded demo listings, not handover evidence or proof of value.

Final assets: `storage/demo/item-photos/*.jpg` (1200 × 900 JPEG). They are versioned separately from member uploads and served through the existing authenticated `photo.php` proxy, using logical paths `item-photos/demo/<slug>.jpg`. Migration 017 fills empty photo lists only. Existing member photos are preserved. Removing a bundled image from a listing never deletes the shared asset.

The existing landing illustration, logos and initials avatars are intentional design elements. Upload controls remain empty until files are supplied. Dispute evidence is never synthesized from item illustrations.
